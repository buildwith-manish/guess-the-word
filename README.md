# Guess the Word by Emoji — Remotion + GSAP (Pattern 1)

A 50-question "guess the word from two emoji" quiz, rendered frame-perfectly with
**Remotion**. GSAP is used only for its **easing math** (Pattern 1: pure
functions in → numbers out, **no GSAP timelines**). The look, timings and copy
match the reference `quiz_short_hook.html` (1280×720 stage, scaled 1.5× to
1920×1080).

```
hook intro → EASY ×20 → bonus → MEDIUM ×15 → bonus → HARD ×15 → scoreboard → end screen
            6s each                                   7s each          8s each
```

Runtime: **≈14:44 at 30 fps** (26 508 frames). Every number comes from
`settings.json` + `rounds.csv`; the composition length is derived, never typed
by hand.

---

## Install

```bash
npm install
```

Node 18+ and a Chromium that Remotion can launch are required; Remotion
downloads its own headless shell on first render.

## Dev (Studio)

```bash
npm run dev          # remotion studio
```

Scrub the timeline like any video editor — because no animation keeps internal
state, every frame can be rendered in any order.

## Render

```bash
npm run render                      # single pass  → out/video.mp4
npm run render:lanes                # chunked, resume-safe (see below)
npm run still -- --frame=700        # one PNG for thumbnails
npm run typecheck                   # tsc --noEmit
node scripts/timeline.js            # print the full frame plan
```

### Resume-safe batches

`scripts/render-batches.js` splits the video into chunks, renders each one with
`remotion render --frames=a-b`, records finished chunks in
`out/.render-progress.json`, and remuxes them losslessly (`-c copy`) into
`out/video.mp4` when the last one is done.

```bash
node scripts/render-batches.js --size 300     # 300-frame chunks (≈10s each)
node scripts/render-batches.js --only 12      # one lane/worker: only chunk 12
node scripts/render-batches.js --concat       # just remux what exists
node scripts/render-batches.js --clean        # wipe chunks + progress
node scripts/render-batches.js --force        # redo everything
```

Kill it at 92 %, run it again: it skips the chunks that already exist.

## Questions & timings

| file | what it controls |
| --- | --- |
| `rounds.csv` | the question bank — `id,word,emoji1,emoji2,level,reveal,fact` |
| `src/rounds.json` | generated by `npm run data`; git-ignored |
| `settings.json` | fps, size, per-level clock, level card length, hook length, bonus rounds, end-screen copy, all UI strings |
| `src/timing.ts` | turns the two files into an exact frame plan used by every scene |
| `src/bonus.ts` | the five seed-generated bonus rounds |

`reveal` is the 1-based letter that flips at the **1/3** mark of the clock (the
"free letter" hint). `fact` is optional and shows on every `factEvery`-th
question (`settings.json → timing.factEvery`).

After editing the CSV:

```bash
npm run data                # rounds.csv  ->  src/rounds.json
node scripts/timeline.js    # sanity-check the new length
```

Levels are read from the `level` column (`EASY`/`MEDIUM`/`HARD`); each level
block gets its own on-screen level card and its own clock length from
`settings.json → levels[].time`.

## Images

Photos are optional: with an empty `src/image-manifest.json` every answer card
renders the `IMAGE HERE` placeholder, exactly like the reference HTML did.

```bash
npm run images             # scripts/fetch-images.js — z-ai image-search CLI
npm run images:resize      # scripts/resize-images.js — ffmpeg → 1280x720
npm run images:refetch     # scripts/refetch-broken.js — repair missing/broken
npm run images:all         # all three, in order
```

* `fetch-images.js` calls `z-ai image-search "<word> photo" --count 5 --json`
  and **rejects any result from `shutterstock.com`** (plus its CDN
  `sscdn.co`/`shutterstock.net` and a few other stock hosts — the list lives in
  `settings.json → images.blockedHosts`). Override the binary with `--bin` or
  `Z_AI_BIN`, the query with `--query`, and the flags sent to the CLI with
  `--cli-args`. It checkpoints to `scripts/.image-progress.json` (git-ignored)
  and is safe to re-run.
* `resize-images.js` normalizes to exactly **1280×720** with
  `scale=...:force_original_aspect_ratio=increase,crop=1280:720` (lanczos).
  It uses `ffmpeg` from PATH, `$FFMPEG_BIN`, or the static binary that ships in
  `node_modules/@remotion/compositor-*`.
* `refetch-broken.js` validates every file (exists, >12 KB, real image header,
  correct dimensions) and repairs only the bad ones. Use `--dry-run` to report.

The video reads `src/image-manifest.json`; a question only shows a photo if its
id is listed there.

## Sound

`public/sounds/` is wired but empty on purpose — `settings.json → sound.enabled`
is `false`. Drop `tick.mp3`, `reveal.mp3`, `stamp.mp3`, `whoosh.mp3` in there,
flip the flag, and add your `<Audio>` tags where you want them; nothing else in
the project needs to change.

## GSAP Pattern 1 in this project

> **GSAP provides easing math via pure functions, Remotion renders frames, no
> GSAP timelines.**

`src/gsap-helpers.js` compiles GSAP eases once and exports them as pure
functions:

| helper | GSAP ease | used for |
| --- | --- | --- |
| `backOut` | `back.out(1.7)` | emoji seats, cards, score rows, answer chips |
| `expoOut` | `expo.out` | reveals, letter blanks, rules, hairlines |
| `elasticOut` | `elastic.out(1, 0.35)` | answer stamps, badges, "GOT IT?" chip |
| `power3Out` / `power2InOut` / `sineInOut` | … | slams, iris wipes, breathing glows |
| `linear` | none | the clock fill only — an eased countdown lies |

`src/anim.ts` is the only bridge between the two worlds:

```ts
const p = prog(frame, start, 18, backOut);   // pure: frame → eased 0..1
style.transform = `translateY(${(1 - p) * 160}px)`;
```

No `gsap.timeline()`, no `gsap.to()`, no `useEffect`, no refs to animate. That
is why:

* any frame can be rendered in isolation (parallel lanes, `--frames=a-b`)
* the Studio timeline scrubs perfectly in both directions
* re-renders are identical frame for frame (all randomness is seeded)

## Notes

* Fonts are bundled and loaded through `@remotion/fonts`, including a colour
  emoji font, so a render never depends on the machine's installed fonts.
* All copy — hook headlines, chips, scoreboard, end screen — lives in
  `settings.json`, so you can re-skin the video without touching a component.
* `public/sounds/` and `settings.sound` are the only audio hooks; the reference
  HTML's WebAudio score is intentionally not ported (Remotion renders audio
  from files, not oscillators).
