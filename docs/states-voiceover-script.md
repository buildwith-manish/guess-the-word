# Video 4 voiceover script: Guess the US State from Its Shape

69 clips. Generated by `npm run states:voiceover:script` (scripts/states-voiceover-script.js); do not edit by hand, change the script or the data and re-run.

- `[emotion]` tags are for ElevenLabs (v3 style audio tags); remove them for a voice/model that reads them aloud. The CSV `public/voiceover/states-lines.csv` is the same text without tags.
- Suggested file name: `public/voiceover/<id>.mp3` (e.g. `r07.mp3`). The ids map to the manifest keys in `src/states/states-voiceover-manifest.json`: `intro`; `levelN` = `level[EASY|MEDIUM|HARD|EXPERT]` in order; `rNN` = `reveal[N]`; `bNq` = `bonusq[N]`; `bN` = `bonus[N]`; rank ids = `scoreboard[id]`; `outro`. A states scan script that fills the manifest is not written yet.
- Reveals and bonus answers are 12 words or fewer (the video holds the answer until the clip ends, so shorter is better).
- The on-screen fun facts are not read: every fact in states-data.ts is still marked unverified.
- Level clocks: Easy 5s, Medium 7s, Hard 8s, Expert 10s.
