# 8a: hint sheets -> transparent PNGs

## Status: DONE. 100 icons for rounds 1-50, manifest lists all 50 rounds, `npm run search:hints` passes.

Source sheets were uploaded as unnamed images; they were identified by content and renamed in a scratch folder (not committed):
files 1,2,3 = sheets 1,2,3; file 4 = sheet 5 (joker); files 5-9 = sheets 6-10; file 10 = sheet 4 (banana).
All ten were 1024x572 RGBA (fully opaque), flattened on white before cutting.

## Files
- `scripts/search-hints-cut.py` (`--src DIR` with `sheet-01.png`..`sheet-10.png`; rebuilds PNGs and `src/search/hint-images.json` from files that exist)
- `scripts/search-hints-qa.js` (`npm run search:hints`; python3 + pillow only to decode PNGs)
- `public/search/hints/hint-NN-1|2.png`, 100 files, 512x512 RGBA
- `src/search/hint-images.json`: rounds 1-50, each `["hint-NN-1.png","hint-NN-2.png"]`

## How the cut went
- Sheets 3-10: equal 5x2 cells worked. Sheets 1 and 2: some objects touch their cell edge, so the connected-components fallback was used (pairs checked by eye).
- Mapping is positional (sheet k, column c -> round 5(k-1)+c, top = image 1). `ROUNDS` ids run 1-50 in order; the contact sheet pairs were checked against that order by eye.
- Background = white or pale colourless pixels connected to the image border, so white inside the outline (eyes, flag squares, owl, jar) stays.
- `HOLE_CELLS` in the cutter makes large enclosed pale regions transparent in four cells where it is a real hole or trapped rim: 01-2 web gaps, 25-1 donut hole, 33-2 microphone cable loop, 35-1 gold ring hole. The leak check therefore flags 35-1 (38%); that is expected.

## Things to check by eye / known defects
- Dark-on-dark: outline-only or dark objects (web 01-2, spider 01-1, skyline 02-2, bat 02-1, paw 15-1, cave 35-2, pirate flag 28-1) have a navy outline (#1B1B2F) and will be hard to see on this video's dark backgrounds. HintClue (8b) should put icons on a light plate or add a light glow.
- 27-1 (flexed arm): the source has no outline on its right end, so that end is soft. Source defect.
- Small Gemini sparkle marks remain in the lower-right corner of some cells (15-2, 25-2, 30-2, 40-2, 45-2).
- 33-2 microphone: the white sticker rim trapped inside the cable loop was removed by the override; check the cable edge.
- 25-1 donut: a faint grey shadow arc remains below the right edge. 35-1 ring has a small notch at the top right (in the source).
- 46-2 wizard staff keeps its yellow glow halo (semi-opaque yellow disc); 18-2 lightsaber keeps a faint pink glow.
- Sources are only ~140-185 px wide, so 512x512 output is soft. Higher-resolution sheets would be sharper.
- Not verified: nothing was viewed in Remotion Studio, and the icons were only viewed on a checkerboard preview (`out/hints-contact.png`, gitignored, not committed).
