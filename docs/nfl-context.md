# NFL Scouting Card Quiz: shared context (task 1a)

Read from this branch (`nfl-quiz`, cut from `gta6-quiz` at tag `gta6-base-1123`, commit 79454ca) and, only where something is missing here, from `origin/search-history` and `origin/us-states`. Paths, exports and props only; no file bodies copied. Nothing was rendered or type-checked.

Rule reminders from the prompts: nothing in `src/nfl/` imports from `src/gta6/` (copy, then rewire). Allowed imports: `src/nfl/`, `src/ios/`, node_modules. 2560x1440 at 60 fps, written in 1280x720 reference units through `px()`.

## 0. Conventions and open decisions

- **Frame:** root `settings.json` = `fps 60, width 2560, height 1440` (same on every branch). Design clock = 30 fps "ticks": `FPS = 30`, `TIME_SCALE = RENDER_FPS / FPS = 2`. Render frame = tick x 2. `useDesignFrame()` (`src/clock.ts`) = `useCurrentFrame() / TIME_SCALE`; gta6 has its own copy, `useGta6Frame()` in `src/gta6/timing.ts`.
- **Unit conflict (decide in 2a).** `src/style.ts` `px(v) = v * SCALE(2)` is the 1280x720 reference unit the NFL Starter requires. **Every `src/gta6/` component is authored in 1920x1080 units through `u(v) = v * WIDTH/1920` (x1.333).** Copying a gta6 component into NFL means converting its numbers: 1920-unit value x 2/3 = 1280-unit value (then `px()`), or giving `src/nfl/system.ts` a `u()` of its own. Do not leave a mix.
- **`px()` and `useDesignFrame` live in `src/style.ts` / `src/clock.ts`, which the Starter's import list does not name.** `src/ios/tokens.ts` itself imports `../style`, so `src/style.ts` is in the graph anyway. Suggested: 2a copies the two helpers into `src/nfl/system.ts` (a few lines) so the rule holds literally.
- **Inter is not loaded anywhere on this branch.** `src/fonts.ts` loads Anton, Poppins, JetBrains Mono and Noto Color Emoji only; gta6's `system.ts` says "the scene must load Inter" and nothing does, so gta6 text falls back to the system font. NFL must import `src/ios/fonts.ts` (missing here, see section 1) once, from Root.
- **Timeline:** plain segments `{ kind, from, to, ... }` built by a private `buildSegments()` with a cursor, `locate(tick) -> { seg, local, index }`, `RENDER_TOTAL_FRAMES = ticksToFrames(last.to)`. Parts are `Sequence`s placed from `partRanges`.
- **Do-not-touch:** `remotion.config.ts` (jpeg 95, h264, yuv420p, CRF 18, concurrency <= 2, `swangle`, delayRender timeout 120000), `package-lock.json` (out of sync: `npm ci` fails, per the gta6 progress notes), all of `src/gta6/`.

## 3. How clip lengths reach timing

1. Generate one wav per id into the clips folder (named `<id>.wav`, ids from `lines.csv`).
2. `clean_gta6_clips.sh` (optional): trim, loudness-normalise to -16 LUFS, originals kept in `raw/`.
3. `build_gta6_timings.py`: ffprobe each clip listed in the CSV -> `timings.csv` + `timings.generated.ts`.
4. `build_gta6_audio_map.ts`: CSV rows -> items -> `audioMap.ts` (`itemAudio`, `levelIds`, ...).
5. `timing.ts` imports `clipTimings` and `audioMap`; `useClipTimings` true when every needed id has a length. Then each phase is the clip length plus a pad, e.g. question = `max(questionMinSec, clip + questionPadSec)`, level card / score card / rank / outro = clip + `cardPadSec`, dyk = `dykLeadSec` + clip, reveal = `max(elimination, clip)`. When false, constants are used. Segments are built with a cursor; `partRanges` and `chapters` are derived from them.
6. `build_gta6_duck.ts` reads the same placement (`voiceTimeline.ts`) and bakes the music envelope; re-run it after every change in steps 1 to 5.
7. The clip files themselves are not committed (`public/gta6/voiceover/` is untracked; originals sit in `clips.7z` at the repo root).

## 6. SFX ids (task 1d)

`scripts/make_nfl_sfx.py` (numpy synthesis + pedalboard high-pass, gentle compressor, limiter) writes 48 kHz mono wavs to `public/nfl/sfx/` plus `manifest.json` and the generated `src/nfl/sfx-ids.ts` (`SFX_IDS`, `SFX_ROWS`). `src/nfl/sfx.ts` exports `SfxId`, `SfxEntry`, `SfxCue`, `cue()`, `sfxIds`, `sfxManifest`, `sfxEntry`, `sfxLength`, `sfxFrames`, `sfxSrc`, `clueFlipId(1..5)`, `pointsDropId(5..1)`. Cue `frame` is a design tick (30 fps). Peak ceiling -3 dBFS.

Ids (25): card-in, clue-flip-1, clue-flip-2, clue-flip-3, clue-flip-4, clue-flip-5, points-drop-5, points-drop-4, points-drop-3, points-drop-2, points-drop-1, lock-shake, lock-open, name-reveal, wallet-stack, notification, streak, tmw-tick, tmw-alert, level-rookie, level-starter, level-hof, score-card, rank-reveal, end-sting.

- `clue-flip-N`: N = clue number, pitch rises with N. `points-drop-N`: N = points left after the drop, pitch falls with lower N.
- `tmw-tick` is exactly 1.0 s (8 ticks), made to be cued once per second.
- Re-run `python3 scripts/make_nfl_sfx.py` after any change (needs `pip install numpy pedalboard`).
